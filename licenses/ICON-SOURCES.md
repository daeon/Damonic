# Nerd Fonts v3.5.1 icon source notices

Damonic Nerd Font Mono includes the glyphs from the official `SymbolsNerdFontMono-Regular.ttf` artifact in [Nerd Fonts v3.5.1](https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1). The vendored archive is accompanied by its MIT license and upstream README. The README records the exact icon sets and versions used by that release:

A license inventory file is stored for every listed source set. License text files fetched from upstream are stored beside this notice where available; the remaining inventory records the exact upstream URL and license term. The authoritative bundled notices are the files shipped inside the pinned Nerd Fonts archive; no icon source is fetched at build time.
