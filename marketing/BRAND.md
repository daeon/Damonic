# Damonic brand brief

## Position
An original open-source humanist monospace for developers who care about both their code and the type they read it in. The current release invites hands-on evaluation and useful feedback.

## Message
**Make room for the code.**
Supporting line: **Four styles. A complete Nerd Fonts edition. One collection.**
Primary action: **Download the free alpha.** Secondary action: **Try the typeface.**

## Visual identity
| Role | Color | Use |
|---|---|---|
| Ink | `#172a32` | Dark backgrounds and primary text |
| Paper | `#f4f1e7` | Light backgrounds and inverse text |
| Lime | `#dafa72` | Calls to action and a short accent line |
| Muted | `#aec0bd` | Supporting text on dark backgrounds |

Damonic is the display face and specimen face. System sans-serif handles longer landing-page explanations and controls. The wordmark is the unmodified name set in Damonic. Preserve proportions; do not tighten individual pairs or stretch artwork.

Use generous margins, simple rules and a limited palette. Let actual letterforms and code carry the composition. Avoid decorative imagery that competes with the specimen. SVG text is outlined for reliable sharing; descriptive titles and accessible labels remain.

## Voice
Direct, curious, technical when useful. State the feature and its practical use. Lead with the font, then packaging and optional controls. Invite specific feedback.

No invented testimonials, review scores, adoption numbers or performance claims. Keep the alpha status visible at the point of download. Do not promise universal compatibility or imply a variable font. Full Nerd Fonts coverage always refers to the pinned 3.5.1 mapping set.
